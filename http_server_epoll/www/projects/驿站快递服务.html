项目简介

本项目是一个基于C语言实现的驿站快递管理系统，采用分层架构设计，通过哈希表（链地址法）实现快递信息的高效存储与检索，结合SQLite实现数据持久化。系统支持快递入库、出库、查询等完整业务流程，并实现了内存与数据库的双写一致性保障。

功能

服务端：

  • 快递入库（自动生成取件码、按类型分配货架）
  • 快递出库（支持按取件码或手机号批量取件）
  • 快递查询（支持手机号查询、取件码查询）
  • 自动过期判定（入库超过14天自动标记为滞留件）
  • 数据持久化（SQLite数据库存储）
  • 双写一致性（内存哈希表与数据库同步更新）

客户端：

  • 终端菜单式交互界面（VT100彩色输出）
  • 快递信息录入与展示
  • 批量取件操作
  • 状态可视化（待取件/已取件/滞留件）

核心技术亮点

1. 哈希表动态扩容机制

系统使用自定义哈希表实现快递信息存储，采用链地址法解决哈希冲突，并实现了负载因子触发的动态扩容机制： 

// 负载因子触发扩容
if ((float)ht->size / ht->count >= LOAD_FACTOR) {
    int new_count = ht->count * 2;
    DeliverNode** new_buckets = (DeliverNode**)calloc(new_count, sizeof(DeliverNode*));
    // 遍历旧桶，重新散列插入新桶
    for (int i = 0; i < ht->count; i++) {
        DeliverNode* curr = ht->buckets[i];
        while (curr) {
            DeliverNode* next = curr->next;
            int new_key = hash_function(curr->data.pickUp_code, new_count);
            curr->next = new_buckets[new_key];
            new_buckets[new_key] = curr;
            curr = next;
        }
    }
    free(ht->buckets);
    ht->buckets = new_buckets;
    ht->count = new_count;
}

关键设计：

  • 哈希函数：采用多项式滚动哈希（seed=31），对取件码进行哈希计算
  • 负载因子：超过阈值时自动扩容，保证查询性能
  • 重哈希策略：桶数量翻倍，使用头插法重新分配节点

2. 双写一致性与失败回滚

系统实现了内存哈希表与SQLite数据库的双写一致性，任何一步失败都会触发回滚： 

int in_station(ExpressStation *es, Deliver *deliver) {
    // 1. 先插入内存哈希表
    if (insert_to_table(es->in_repository, deliver)) {
        return 1;
    }
    // 2. 再同步到数据库，失败则回滚内存
    if (db_insert_in_repository(deliver) != 0) {
        delete_from_table(es->in_repository, deliver->pickUp_code, NULL);
        return 1;
    }
    return 0;
}

3. SQLite事务保护

出库操作涉及两个原子操作（从入库表删除、插入出库表），使用SQLite事务保证原子性： 

// 开启事务
sqlite3_exec(g_db, "BEGIN TRANSACTION;", NULL, NULL, &err_msg);

// 1. 从入库表删除
sqlite3_prepare_v2(g_db, "DELETE FROM in_repository WHERE pickUp_code = ?;", ...);

// 2. 插入出库表
sqlite3_prepare_v2(g_db, "INSERT INTO out_repository ...", ...);

// 提交事务
sqlite3_exec(g_db, "COMMIT;", NULL, NULL, &err_msg);

关键设计：任意一步失败都执行 ROLLBACK，保证数据一致性。

4. 分层头文件架构

通过分层设计解决结构体交叉引用问题： 

common.h        ←  定义 Deliver、DeliverNode、枚举等基础类型
    ↑
hash_table.h    ←  包含 common.h，定义 HashTable
    ↑
express_service.h  ←  包含 common.h + hash_table.h，定义 ExpressStation
    ↑
ui.h / main.c   ←  只包含 express_service.h
