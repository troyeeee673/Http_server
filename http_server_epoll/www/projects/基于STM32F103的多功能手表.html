⌚ 基于STM32的多功能电子手表

🏷️ 嵌入式 STM32 驱动开发 MPU6050 姿态解算 分层架构
基于STM32F103平台，采用分层驱动架构实现的多功能电子手表，集成MPU6050姿态解算、电池管理和多级菜单系统。

项目简介

本项目基于STM32F103C8T6平台，从底层驱动到上层应用完整实现了一款多功能电子手表。项目采用分层驱动架构（APP/BSP/Driver/Service四层），独立封装了ADC采样、软件I2C通信、MPU6050传感器驱动、按键检测等硬件抽象层，并在此基础上构建了姿态解算、电池管理、输入事件处理等应用服务。最终实现了时钟显示、水平仪、秒表计时、小游戏等完整功能。

基础功能：

核心技术实现

1. 软件模拟I2C通信协议

使用GPIO（PB10/PB11）在标准IO口上实现完整的I2C主机通信协议，驱动MPU6050传感器和OLED显示屏：

  • 严格遵循I2C时序规范（起始条件、停止条件、ACK/NACK检测）
  • 支持单字节/多字节连续读写
  • 实现设备地址+寄存器地址的标准访问模式
// I2C连续读取MPU6050六轴数据（14字节）
uint8_t DrvMpu6050_ReadReg(uint8_t regAddress)
{
    uint8_t ucData;

    DrvI2cSoft_Start();
    DrvI2cSoft_SendByte(MPU6050_ADDRESS);
    DrvI2cSoft_ReceiveAck();
    DrvI2cSoft_SendByte(regAddress);
    DrvI2cSoft_ReceiveAck();

    DrvI2cSoft_Start();
    DrvI2cSoft_SendByte(MPU6050_ADDRESS | 0x01);
    DrvI2cSoft_ReceiveAck();
    ucData = DrvI2cSoft_ReceiveByte();
    DrvI2cSoft_SendAck(1);
    DrvI2cSoft_Stop();

    return ucData;
}

2. MPU6050姿态解算与互补滤波

独立完成从原始六轴数据到姿态角的完整处理链路：

  • 原始数据采集：通过软件I2C读取三轴加速度+三轴陀螺仪数据
  • 加速度计倾角计算：利用重力分量反算Roll/Pitch静态倾角
  • 陀螺仪角速度积分：对角速度进行时间积分获得动态角度
  • 互补滤波融合：利用加速度计低频准确性与陀螺仪高频响应性，通过互补滤波器消除积分漂移
// 互补滤波核心公式
angle = 0.98 * (angle + gyro * dt) + 0.02 * accel_angle;

滤波器参数通过 project_config.h 集中配置，便于调试与优化。

3. 1ms精确时基调度系统

基于TIM2硬件定时器构建系统时基，实现多任务精确调度：

  • 配置TIM2为1ms周期中断
  • 中断服务函数统一调用 Bsp_Tick1ms() 分发入口
  • 驱动多个周期性任务：按键扫描消抖、秒表计时、游戏帧更新、OLED刷新
void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        Bsp_Tick1ms();  // 统一分发至各模块
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}

这种设计避免多处配置定时器导致的资源冲突，保证系统时序一致性。

4. 按键事件识别与消抖

input_service 模块实现按键状态机，支持短按与长按事件识别：

  • 消抖处理：连续多次采样确认，消除机械抖动
  • 长按检测：可配置长按时间阈值（通过 project_config.h 设置）
  • 事件缓存：缓存按键事件供上层应用轮询消费
  • 定义 emKeyEventTdf 枚举类型，统一事件语义（短按/长按/按下/释放）

5. ADC电池电压监测

battery_service 模块实现完整的电池监测功能：

  • 均值滤波：配置N次采样取平均（project_config.h 中可调），有效抑制ADC噪声
  • 电压换算：Vbat = (float)ADValue / 4095 * Vref，避免整数除法精度损失
  • 电量映射：根据锂电池放电曲线将电压分段映射为0-100%电量
  • 提供 BatteryService_GetVoltage() 和 BatteryService_GetCapacity() 统一接口

6. 工程化代码规范

项目全程遵循一套自定的嵌入式编码规范：

  • 文件头注释：统一 @file、@author、@version、@date、@brief 格式
  • 命名约定：
    • 设备层枚举使用 em...Tdf 前缀，结构体使用 st...Tdf 前缀
    • 模块私有函数使用 s_ 前缀
    • 局部变量使用类型语义前缀（uc无符号字符、us无符号短整型、st结构体、em枚举）
  • 集中配置：BSP/project_config.h 集中管理所有可调参数（采样次数、阈值、滤波系数等）
  • 接口注释：所有公开函数包含 @brief、@param、@retval 文档注释
