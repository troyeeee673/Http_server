⚖️ 基于STM32的两轮平衡车控制项目

🏷️ 嵌入式 STM32 平衡车 电机控制 MPU6050 PID控制
基于STM32F103平台实现的两轮平衡车控制工程，集成MPU6050姿态采集、编码器测速、电机PWM驱动、按键控制与电池状态检测。

项目简介

这个项目是一个基于 STM32F103 的两轮平衡车控制工程，在嵌入式系统层面把传感器采集、姿态估计、电机驱动、编码器测速、按键控制和电源状态管理串联起来，同时集成移动端的简单控制app，形成一个可运行的、完善的控制平台。

这个项目偏向控制系统与驱动实现，并且兼顾移动端app开发：它使用 MPU6050 读取姿态信息，利用编码器实现轮速反馈，并通过 PWM 驱动 TB6612 驱动芯片控制左右电机。

项目目标

这个平衡车项目的核心目标是搭建一套可验证的嵌入式控制链路：

  • 通过 MPU6050 获取车体姿态数据
  • 通过编码器获取左右轮的转角与转速信息
  • 通过 PWM 控制电机输出，实现车轮驱动
  • 通过按键和电压检测模块完成基础交互与状态管理
  • 将这些模块组织成一个便于调试和扩展的工程结构

主要功能

1. 姿态传感与数据采集

项目中使用了 MPU6050 六轴传感器，通过 I2C 通信读取加速度和陀螺仪数据，获取车体的姿态相关信息：

  • 加速度数据：用于辅助判断车体倾斜方向
  • 陀螺仪数据：用于获取角速度变化
  • 温度读取：用于辅助传感器状态监测

代码中通过独立的 MPU6050 模块完成初始化、数据更新和读取接口封装，便于后续控制算法接入。

2. 电机驱动与PWM控制

项目使用 STM32 的定时器输出 PWM，并通过 TB6612 驱动芯片控制左右电机：

  • 左右电机分别由独立的 PWM 输出口驱动
  • 通过方向控制信号实现正反转
  • 通过占空比控制实现速度调节

这部分代码体现了典型的嵌入式电机控制思路：硬件引脚配置、PWM 初始化、方向控制逻辑以及占空比映射都已经完整实现。

3. 编码器测速与反馈

为了获得轮子的实际运动状态，项目加入了编码器模块：

  • 通过外部中断捕获编码器信号
  • 统计左右轮转角变化
  • 计算转速信息

这一层是平衡车控制中非常关键的反馈路径。即使当前工程还偏向底层验证阶段，编码器模块已经具备了后续闭环控制的基础条件。

4. 按键控制与状态切换

项目中还封装了按键模块，用户可以通过按键触发电机使能状态切换：

  • 单击按键可以切换电机使能状态
  • 按键逻辑通过独立模块封装，便于后续扩展为启动、停止、模式切换等功能

5. 电池电压与状态指示

工程中还包含电池检测与状态显示模块：

  • 通过 ADC 采样电压信号
  • 根据电压等级切换 LED 状态指示
  • 为后续低电压保护或电量提示提供基础设施

技术实现特点

硬件接口设计

项目整体采用了较清晰的嵌入式模块划分：

  • MPU6050 模块：负责传感器初始化与数据读取
  • PWM 模块：负责电机驱动输出
  • 编码器模块：负责反馈量采集
  • 按键模块：负责简单的人机交互
  • 电池模块：负责电源状态检测

这种分层方式使得每个功能都能单独调试，后续再接入控制算法时也更容易维护。

中断驱动与实时处理

编码器模块使用外部中断来捕捉脉冲变化，这种方式能够快速响应轮子状态变化；同时，项目中也使用了定时器和中断相关机制，说明其已经具备了较真实的嵌入式控制系统特征。

代码组织风格

从代码结构上看，项目有明显的驱动层 + 应用层风格：

  • 低层驱动文件负责底层硬件配置
  • 应用层文件负责功能组织与状态流转
  • 测试文件用于分模块验证各个功能点

这说明它不仅是一个简单的 demo，而是一个具备工程化意识的单片机项目。

代码结构说明

项目目录中主要包含以下几类内容：

  • user：核心应用代码，包含主程序和各个功能模块
  • test：各模块的测试代码，用于验证传感器、PWM、电机和编码器效果
  • std_periph_driver：STM32标准外设库驱动文件
  • startup：启动代码与工程初始化文件
